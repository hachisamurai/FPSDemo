# 敌人战术与Boss第二阶段

后续已新增[近战怪与冲刺怪](近战怪与冲刺怪.md)：近战绿灯、冲刺橙灯，由独立CloseCombat组件接管，不发射飞行物。当前固定战役与无尽按关号随机混编：普通关只近战/冲刺，每5关加入远程，每10关在三种小怪之外追加Boss，详见[战役配置与难度](战役配置与难度.md)。下文原战术组件能力及MixedRoles仍支持直接生成，但生产战役角色选择不再由MixedRoles决定。

## 目的与设计理念

按用户选择的标准强度，让玩家通过移动、冲刺和控制技能应对不同方向的压力。复用现有NavMesh与GAS伤害，新增C++战术组件，不需要手动连接行为树/黑板。新增角色不增加血量、伤害或怪物数量；伤害和双币奖励仍来自原关卡/难度配置。

`UDemoEnemyTactics`决定移动目标、有限预判与二阶段节奏；`UDemoEnemyNavigation`计算完整路径并Sweep执行；`ADemoEnemy`负责阶段、施法、冰冻门控和攻击。三个组件没有各自独立移动Tick，避免冻结或前摇期间发生隐藏位移。

## 玩法与执行流程

1. `DemoCombatConfig::Resolve`冻结模板Tactics；GM逐怪填写FormationSlot，Mixed按MixedRoles循环分配（默认追击/远程/侧翼/近战/冲刺），左右按编队序号交替。同一关重开阵容稳定；现有存档不保存活怪角色，重新开始战斗时由当前表生成。
2. 追击兵为红色，追近至130cm，速度乘1.25；保留原近战和飞行物。远程兵为蓝色，近于550cm回退，保持850cm左右并小幅侧移；侧翼兵为紫色，寻找玩家周围650cm、相对自身径向偏65度的位置，速度乘1.25。远程和侧翼被贴脸时仍保留原190cm三维近战条件，不能用战术距离扩大近战伤害范围。
3. 看不见玩家或超过1100cm时先寻路接近。可见后每2.5秒选择新的战术点，必须投影成功、完整可达且终点有视线。失败按战术周期重试，其间回退旧追击，避免每帧左右换目标；仍不瞬移、不忽略墙体。候选是本地启发式分工，不是全局站位预约或完整Crowd系统。
4. 首发至少等待2秒，再增加`(FormationSlot % 7)*0.17`秒，避免所有敌人入场同帧齐射。远程/侧翼和默认Boss按发射时玩家速度进行最多0.3秒、180cm提前量预判；冲刺躲避窗口中不外推。弹体不追踪玩家，变向仍能躲避；实际玩家视线被墙阻挡时禁止发射。
5. Boss生命首次降至50%且仍活着时，通过真实GAS健康委托锁存第二阶段，机体变为紫红色，日志`AI_BOSS_PHASE2`。治疗不退出，致命一击不触发。未来攻击间隔乘0.75，移动乘1.15；不刷新已开始的冷却，不取消或缩短进行中的预警。
6. Boss默认投射物间隔1.8→1.35秒，地面攻击2.6→1.95秒，全图开始间隔10→7.5秒。原地面0.9秒预警、全图2秒红光前摇、冲刺躲避全图后回复5HP全部保留。全图开始间隔最低3秒；移动继续乘GAS移速倍率，Frozen只禁止移动，沿用既有“定身不封攻击”语义。
7. 非Combat/死亡/取消施法清临时目标；暂停用World时间冻结决策和冷却。没有异步Lambda、定时追击任务或玩家强引用；当前仅支持原单人权威逻辑，不新增完整联机AI。

## 配置与使用

源文件为`Config/Combat/Enemies.json`的`Tactics`对象，运行资产为`/Game/Data/DT_Enemies`。JSON不支持注释，字段意图和范围在本文维护。通过`Tools/Unreal/import_combat_tables.py`由Unreal Editor创建/更新资产，禁止手写uasset；新增USTRUCT后先完整编译Editor再导入。也可在表编辑器展开Tactics修改，但下次JSON导入会覆盖表内修改。只影响后续生成的敌人。

| 字段 | 默认 | 范围与用途 |
|---|---|---|
| bEnabled | true | false恢复旧追击、瞄准和攻击节奏 |
| Role | Drone=Mixed、Warden=Ranged | Mixed/Chaser/Ranged/Flanker/Melee/Charger；Boss始终用Boss移动，Ranged开启有限预判 |
| MixedRoles | 五类各一项 | 1..16项非Mixed角色数组，重复条目可调整混编比例 |
| MinimumRange | 550cm | ≥250，小于PreferredRange；远程回退阈值 |
| PreferredRange | 850cm | 两个阈值之间，远程目标半径 |
| MaximumRange | 1100cm | ≤2500且≤Attack.ProjectileRange，超过则接近 |
| RepositionInterval | 2.5秒 | 1..6，选点和失败重试周期 |
| FlankRange | 650cm | 300..1500，侧翼环半径 |
| PressureSpeedMultiplier | 1.25 | 1..2，仅追击/侧翼速度 |
| PredictionSeconds | 0.3秒 | 0..0.6，实际提前量另有180cm上限 |
| RageHealthFraction | 0.5 | 0.1..0.9，二阶段健康阈值 |
| RageIntervalMultiplier | 0.75 | 0.5..1，仅二阶段未来冷却 |
| RageSpeedMultiplier | 1.15 | 1..1.5，二阶段移速，继续受GAS影响 |

频率基础值仍在Attack对象，生命/伤害继续按原等级和难度乘算。Tactics不会被难度倍率重复放大。所有浮点值验证有限值、上下限和距离顺序，错误表拒绝开局并报行名。直接C++生成需显式`Stats.bUseTactics=true`，提供合法Tactics与非负FormationSlot；旧直接调用默认false以保持明确的旧测试/工具行为。非法直接配置记录警告并禁用战术。

## 依赖、调试与失败处理

依赖现有NavigationSystem/Recast、`ADemoEnemy` ASC与`MoveSpeedMultiplier/Frozen`状态、GameState Combat守卫。沿用平坦竞技场悬浮导航限制，不提供楼梯/三维飞行。密集怪群可能互相挡弹或等待；无路径回退只尝试追击，不保证不可达玩家能被强行接近。

日志`AI_ROLE`用于查看出生角色/序号，`AI_TACTIC`记录Chase、SeekSight、Retreat、Strafe、Flank、FallbackChase、BossAdvance；`AI_BOSS_PHASE2`记录阈值和倍率。每个功能入口有调用埋点；高频使用DEMO_LOG_TICK，状态改变才输出普通Log。`Demo.AI.DebugNavigation 1`显示实际路径与TacticalMove/TacticalNoPath/TacticalNoSight等导航原因，角色以机体颜色识别。

## 验证方法

在独立Editor-Cmd游戏进程使用`-DemoEnemyAttackTest -DemoEnemyTacticsTest -nullrhi -unattended -nosound`，地图`/Game/Whitebox/Maps/L_ThreeSector_Whitebox`。沿用EnemyAttackTest隔离存档和禁云规则，不单独裸用TacticsTest参数。成功标记`DEMO_ENEMY_TACTICS_SUCCESS`；失败为`ATTACK_TEST FAIL`。不能只看退出码。

专项检查生产DataTable/GM混编、错误配置拒绝、真实NavMesh回退拉距、冰冻禁止战术位移、实际侧翼横移、有限预判和生成弹体方向、真实GAS跨半血锁存、治疗不退出、二阶段固定前摇与非Combat停止。并复跑原`-DemoEnemyAttackTest`和`-DemoEnemyAttackTest -DemoEnemyNavigationTest`，验证碰撞、躲避回血、冷却、绕墙、死亡/阶段取消。

人工验收：第一关观察近战绿灯与冲刺橙灯，第5关观察远程兵并贴近验证回退；左右变向验证非追踪弹可躲；第10关在三类小怪之外将Boss降至半血，观察机体变色和节奏，确认全图红光仍2秒且冲刺躲避回血。自动化不等同于最终手感平衡和密集怪群性能验收。

## 影响文件与维护

新增`AI/DemoEnemyTactics.h/.cpp`、`Tests/DemoEnemyTacticsTest.cpp`；修改`AI/DemoEnemy.*`、`AI/DemoEnemyNavigation.*`、`Game/DemoCombatConfig.*`、`Game/FPSDemoGameMode.cpp`、`Tests/DemoEnemyAttackTest.*`、`Config/Combat/Enemies.json`和Editor导入的`Content/Data/DT_Enemies.uasset`。现有导入工具同时保存另两张配置表，但其源配置没有改变。

修改角色数量需同步Mixed枚举映射、出生测试和颜色；修改远程射程需同步战术范围校验。增加敌人动画/楼梯时应迁移标准Pawn/AIController/PathFollowing，再将本组件决策接入行为树，不能继续堆积平面移动补丁。不要把Tactics状态写进永久档案或从同步查询改为无生命周期保护的异步捕获。
