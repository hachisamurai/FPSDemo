# 敌人攻击、Boss全图技能与冲刺躲避

新增[近战怪与冲刺怪](近战怪与冲刺怪.md)是两类纯近身角色：Melee/Charger不使用本文旧飞行物和即时接触攻击，改为可打断前摇/直线突进；Chaser/Ranged/Flanker及Boss继续保留本文行为。冲刺窗口现在也可躲开Charger突进碰撞，但不给回血，普通近战仍需实际移动避开。

## 目的与设计

在现有GAS十关战役中叠加攻击方式：小怪保留近战，Boss保留0.9秒锁定地面范围攻击；两者新增可走位躲避的直线飞行物。Boss再新增“2秒红光蓄力→全图结算”。所有健康变化仍通过玩家PlayerState ASC、敌人自有ASC和Health GE执行，不在碰撞里直接改HP。

全图技能的**有效范围是当前战斗关卡的玩家**，不受墙体、距离或原4500cm索敌距离限制。释放时冲刺窗口生效则成功躲避并通过GE回复5HP，受MaxHealth钳制；取消/杀死Boss不算躲避，不奖励回血。冲刺窗口固定0.45秒、从成功Commit的Dash动作开始计时，与4秒冲刺冷却不同。过早冲刺会在全图释放前失效。这个窗口只免疫Boss全图技能，普通近战、地面范围和飞行物仍可命中；飞行物可通过实际位移躲开。

本功能继续支持单人Standalone/单人PIE。Actor及属性的复制基础不等于完整多人预测、特效广播和输入同步。

新增[Boss升空俯冲](Boss升空俯冲.md)：蓝光悬停3秒无敌、锁点斜砸、固定50伤害与击退。它与本模块攻击互斥；原全图红光2秒和冲刺躲避+5HP不变，新俯冲躲避不回血。配置在怪物表DiveSlam对象。

## 执行流程

### 飞行物

1. 敌人Tick独立检查发射冷却、存活玩家、Combat、发射距离和Visibility视线；墙体和敌人可阻挡发射视线。
2. Deferred生成 `ADemoEnemyProjectile`，以发射瞬间的目标快照计算世界方向；启用战术的远程/侧翼/Boss有限预判最多0.3秒、180cm（可配置），冲刺窗口不外推，详见[敌人战术与第二阶段](敌人战术与第二阶段.md)。快照来源GAS AttackPower和关卡编号。
3. 球半径12cm，ProjectileMovement无重力、非追踪、扫掠碰撞；忽略发射者，最长存活6秒。`bInitialVelocityInLocalSpace=false`，避免FinishSpawning再次旋转已经是世界空间的速度。
4. 首次阻挡碰撞先标记已消耗：碰到玩家且仍在合法战斗则施加一次负Health GE；碰到墙或其他怪只销毁，不造成友伤、不穿透。
5. 来源死亡/被销毁、换关、离开Combat都撤销在途弹。运行时不保留敌人/ASC强引用。

发射点在敌人碰撞中心并忽略自身，避免将外偏枪口放到墙后。初次发射至少保留2秒出生缓冲，启用战术时按出生序号增加0..1.02秒错峰；后续间隔独立于原攻击。

### Boss全图攻击

1. Boss配置冷却到期、没有进行原地面预警时开始全图技能，记录关卡编号。
2. 固定2秒前摇；敌人Tick停止位置更新，也不执行其他攻击。自身球壳显示红色加法发光材质，红色点光源脉动。
3. UObject绑定定时器到期，先消费当前施法状态、关闭红光，再重新检查来源存活、Combat、原关卡和玩家生命。
4. 从Boss**当前世界位置**生成0.4秒扩散球壳。这是释放表现，伤害在2秒结束时即时全图结算，不跟随球壳距离延迟，也不会由球壳二次伤害。
5. `IsDashEvading()`为true：跳过本次伤害和减速，只施加+5 Health GE一次。否则使用Boss此刻的GAS攻击力施加负Health GE；实际扣血且玩家仍活着才施加减速。
6. 减速由 `UDemoSlowEffect` 临时Override `MoveSpeedMultiplier`，默认0.5倍/3秒；属性委托驱动650cm/s基础步速变为325cm/s。重复命中替换/刷新同类效果，不叠乘；到期GAS自然恢复1倍。冲刺初速度独立，不因减速被砍半。

## 使用与配置

编辑 `Config/Combat/Enemies.json` 的 `Drone.Attack` / `Warden.Attack`（实际JSON是Name行内的Attack对象），然后通过Editor运行 `Tools/Unreal/import_combat_tables.py`，更新 `/Game/Data/DT_Enemies`。也可在UE表格编辑器的Attack展开字段直接修改；之后重新导入JSON会以JSON为准覆盖。存活怪物已经冻结配置，修改后从新开局或下一次生成观察结果。

| Attack字段 | 小怪默认 | Boss默认 | 单位与合法范围 |
|---|---:|---:|---|
| MeleeInterval | 1.2 | 1.2（Boss不用） | 原近战间隔，秒，0.2..60 |
| AreaInterval | 2.6（小怪不用） | 2.6 | 原Boss范围技能开始间隔，秒，1..60 |
| ProjectileInterval | 2.4 | 1.8 | 飞行物开始间隔，秒，0.2..60 |
| GlobalInterval | 10（小怪不用） | 10 | 全图两次开始间隔，秒，3..120，含2秒前摇 |
| ProjectileSpeed | 1000 | 1200 | cm/s，200..5000 |
| ProjectileRange | 3500 | 3500 | 三维发射距离cm，200..4500 |
| SlowMultiplier | 0.5 | 0.5 | 全图命中后的步速倍率，0.1..1 |
| SlowDuration | 3 | 3 | 减速持续秒，0.1..15 |

这些参数不随等级/难度倍率改变。启用Tactics的Boss半血第二阶段对后续开始冷却乘RageIntervalMultiplier（默认0.75），不刷新进行中冷却、不缩短预警。三种攻击的伤害都使用GAS AttackPower，飞行物在发射时快照，两个Boss范围攻击在释放时读取。全图前摇固定2秒、躲避奖励固定5HP；没有额外随机倍率。

所有数值都验证NaN/无穷和范围。数据表校验失败时禁止开局并报告行名；直接C++生成传入非法Attack快照则打印警告、使用默认配置。没有通过将间隔设0关闭技能的隐含约定。

## 资产与接口

- `AI/DemoEnemyAttackSettings.*`：可反射Attack结构与校验，由怪物表和生成快照共用。
- `AI/DemoEnemy.*`：独立冷却、前摇、红光、全图结算；`TryFireProjectile`、`TryStartGlobalAttack`为带完整条件检查的行为入口。
- `AI/DemoEnemyProjectile.*`：扫掠弹道、一次性碰撞伤害、来源/关卡校验。
- `AI/DemoAttackPulse.*`：无碰撞扩散球壳，仅释放表现。
- `GAS/DemoEffects.*`、`DemoTags.*`、`DemoAttributeSet.*`：DashEvading/Slowed状态和移动倍率属性；不改共享GE CDO。
- `Characters/DemoCharacter.*`：成功冲刺授予0.45秒GE；移动委托随Avatar解绑；离开战斗清除短期状态。
- `Game/DemoCombatConfig.*`、`Config/Combat/Enemies.json`、`/Game/Data/DT_Enemies`：数据表→冻结攻击配置。
- `Game/FPSDemoGameMode.cpp`：切到非Combat时同帧撤销敌人前摇/在途弹和玩家短期状态，保留原冷却及局内成长。
- `Tools/Unreal/create_enemy_attack_vfx.py`：Editor API创建 `/Game/VFX/EnemyAttacks/M_EnemyGlow`，红色Unlit/Additive/双面/Fresnel透明度；球体与材质是可Cook资产，不靠DrawDebug充当新技能特效。绝不直接写uasset。
- `Tests/DemoEnemyAttackTest.*`：独立真实World测试，`-DemoEnemyAttackTest`启用，普通游戏和Shipping不自动生成测试Actor。

## 边界与维护

Boss死亡/EndPlay/阶段切换精确清除两个Timer并关闭红光。全图释放先清除pending标志，再处理GE，防止死亡委托重入。飞行物同样先消耗后施加伤害。安全区、Reward、Intermission、胜败阶段不接受新敌人攻击，也不会因为取消技能发回血奖励。

原近战和0.9秒地面范围攻击保留；全图前摇拥有更高调度优先级，期间暂停其他攻击，结束后按各自冷却继续，不补发连串积压攻击。Boss首次全图要等待GlobalInterval；原范围前摇未结束时全图开始可能稍晚。暂停世界会同时暂停Timer、移动和窗口时长。

红光材质必须先在Editor创建/保存，之后重启编辑器重新载入CDO硬引用。首次创建资源之前启动commandlet会有一次缺资源提示；资源保存后新进程应无此警告。修改路径必须同步原生硬引用与创建脚本。
