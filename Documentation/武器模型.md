# Breach 四款武器静态模型

## 目的与设计

按已确认的 `Art/Weapons/Concepts/Breach_Weapons_Concept_v1.png` 制作可编辑的 Blender 硬表面实模，并接入既有武器蓝图。统一深灰金属、灰白护板、橡胶握把和少量青色标识；手枪紧凑、步枪弯弹匣、霰弹粗枪口与宽护木、狙击长枪管与光学镜形成不同轮廓。预览图来自真实几何渲染，不是概念图。

采用静态网格符合当前需求。Blender 中套筒、弹匣、扳机、枪托、镜筒等保留独立零件，导出副本才应用倒角并合并。UE 运行时整枪为单个 StaticMesh，继续使用模板手臂动画；不声称已经制作独立弹匣脱落、套筒往复或拉栓动画。未来做骨骼武器可用源零件继续拆分绑定。

## 建模与导入执行流程

1. `Tools/Blender/build_breach_weapons.py` 仅在独立后台 Blender 进程中恢复空场景，使用米制、+X 朝枪口、+Z 向上、握把参考点为原点。
2. 创建各型号集合、共享 PBR 色材质与可编辑零件，真实镂空扳机护圈、空心枪口、镜筒、倒角和加权法线。散热孔使用深色嵌件而非穿透布尔，控制细节成本。
3. 复制源零件到临时导出对象，应用修改器并合并，Smart UV 展开 UV0，导出三角形 FBX。保留源对象修改器以便继续调形。
4. FBX 导出副本单独镜像 Y 并翻转面朝向，配合项目白模已验证的 `axis_forward=-Y/axis_up=Z` 导出规则；UE 逐轴比较包围盒，包括非对称的狙击拉机柄，防止单位或坐标轴错误。
5. 生成四张 Workbench 实模渲染，保存 `.blend` 和清单；`assemble_weapon_previews.py` 仅等比排版为中文标签总览。
6. `Tools/Unreal/import_breach_weapons.py` 显式加载 StaticMeshEditor（commandlet 默认不自动装载），导入专用目录，按 FBX 材质槽名称绑定共享材质、创建三个 Socket、生成 LOD0/1/2 和简单盒碰撞后保存。
7. 只写四个既有 BP 的外观字段：StaticMesh、AttachOffset、HideSupportArm。编译 BP 后重新读取确认指向正确网格。任何步骤失败抛异常；必须同时检查退出码与 `BREACH_WEAPONS_IMPORT_SUCCESS`。

Blender/Python、UE Python 插件和 StaticMeshEditor 仅用于资产制作；运行模块没有新增 UnrealEd 或 Blender 依赖。UE 材质使用常量 PBR，无外部纹理。Armor/Body/Steel 等槽共享材质；Cyan 带低强度自发光。

## 清单字段与可配置项

`Art/Weapons/Models/weapons_manifest.json` 不支持注释，字段含义在此维护：

- `version=1`：清单结构版本；`units=centimetres`：所有 Socket 与 bounds 数值单位。
- `palette`：键是材质角色，每项为 `[线性 RGBA, metallic, roughness]`，两个标量范围 0..1。
- `weapons[].name/asset`：型号稳定后缀和 UE 资产名；`preview_width_m` 是 Blender 取景参考米数。
- `muzzle_cm/grip_l_cm/sight_cm`：局部厘米坐标，用于 Muzzle、Grip_L、Sight Socket。
- `triangles`：应用倒角后的导出 LOD0 三角形数；`bounds_cm`：最小/最大三维包围盒，用于导入轴与单位校验，容差 0.15cm。

LOD0 保留完整模型；LOD1 目标 50% 三角形、屏幕尺寸阈值 0.15；LOD2 目标 25%、阈值 0.06（实际简化结果由引擎约束决定）。UV0 为非重叠智能展开，UE 生成光照 UV；当前实时第一人称不依赖烘焙贴图。简单盒碰撞仅为资产预备，持枪组件强制 NoCollision。

`Config.StaticMesh` 非空优先于 `Config.Mesh`，两者至少有一个；旧骨骼字段保留可回退。`Config.AttachSocket=GripPoint` 位于手臂上；`MuzzleSocket=Muzzle` 位于静态枪上。Grip_L/Sight 预留后续 IK/机械瞄具扩展，当前不运行 IK。不要把相机 FOV 开镜误当作模型内实时光学镜。

## 第一人称运行流程与接口

`OnConstruction / InitializeForOwner → ApplyVisualMesh → AttachToComponent(手臂 GripPoint) → AttachOffset → SetEquipped → GAS 射击/装填/瞄准`。

`ADemoWeaponBase` 保留原骨骼根组件以兼容蓝图序列化；静态模式清空根上的骨骼资源，新 StaticWeaponMesh 子组件为恒等变换。武器隐藏、换枪和开镜沿用整 Actor 可见性；实际弹道、枪声和枪口粒子均读选定外观的 Muzzle Socket。

模板 GripPoint 待机相机相对旋转约 Pitch=-11.26°、Yaw=-73.99°、Roll=-0.25°。导入脚本写入其逆旋转 `AttachOffset: P=2.84645/Y=74.28632/R=10.90161`，比例 1、位移 0，避免修改模型坐标轴。`ADemoCharacter` 手臂位置由模板 `(-30,0,-150)` 调为 `(-10,0,-147)cm`，整体前移 20cm、上移 3cm，手与挂点一起移动，保持握持关系而不改相机或胶囊。

手枪 `bHideSupportArm=true`：装备时隐藏模板 upperarm_l 子树，提供单手展示；切到任何长枪恢复左臂。只有新装备武器写共享手臂状态，库存枪的隐藏操作不抢占当前姿势。缺失骨骼只记录警告并保留现状；没有修改碰撞或物理身体。所有新增 C++ 功能入口/状态及脚本函数都有日志和用途注释。

## 边界、失败与维护

- 缺失 FBX、未知材质槽、轴/单位偏差、生成 LOD 失败、BP 缺失或保存失败均中止并留下错误日志；部分前置资产可能已保存，修正后可幂等重跑。
- 缺失玩家挂点仍拒绝装备；缺失枪口挂点记录警告并沿用旧相机回退。导入和专项测试会要求四把交付网格有真实 Muzzle。
- 原有相机到枪口的防穿墙检测保留，长狙击枪不会因模型枪口深入墙后而越墙命中。
- 当前仅适配模板手臂骨架与单人 Standalone/单人 PIE，不增加完整联机复制。替换手臂、动画或 GripPoint 后需要重新测量 AttachOffset 与支持臂隐藏骨骼名。
- 模型可编辑和可运行，但静态枪不具备独立装填零件动作，也没有专用手枪动画或左手 IK；本次单手手枪是表现适配。
- 单纯修改材质/几何无需修改 GAS。修改枪口坐标必须同步清单和重导入，确保实际弹道起点与外观一致。
