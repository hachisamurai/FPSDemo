# 武器系统设计与实现

## 已确定的规则

- 新建存档初始只有手枪（副槽2），主槽1为空；同槽死亡/主动放弃保留已装备主枪和主副槽选择，重生补给后继续使用。简单完整通关解锁步枪；普通解锁散弹枪；困难（含手枪挑战）或地狱同时满足散弹枪与狙击枪解锁，无需先完成普通。解锁不自动发枪，首次需在安全区/关间的升级终端“武器”页选择并装备。B不再轮换型号；1/2切换已装备的两槽。完整规则与存档结构见[武器库与玩家存档](武器库与玩家存档.md)。
- BP派生类在Class Defaults配置Mesh、WeaponAnimLayerClass、Socket/偏移、RPM、伤害、弹匣/初始弹药/备用弹药、每发消耗、装填秒数、散布/射程/衰减、声音/特效和狙击镜参数。四把枪已迁移为Breach轻量骨骼枪，StaticMesh清空，动画资源统一由武器子AnimBP的AnimSet配置。旧静态模式仅供外部未迁移武器兼容，StaticMesh非空仍优先。模型源、挂接与导入说明见[武器模型](武器模型.md)。
- `Config → UI → Weapon Icon`为可选的 `TSoftObjectPtr<UTexture2D>`；终端打开武器页时异步加载并由HUD强引用缓存，不在武器Actor中硬加载。未配置或失败显示现有轮廓，具体生命周期/Cook约定见[武器库与玩家存档](武器库与玩家存档.md#可配置icon软引用异步加载与生命周期)。
- 左键Started发起射击；自动武器用武器间隔调度下一枪，Completed/Canceled停止。半自动武器每次按下只射击一次。
- 最后一发打完不会立即换弹；弹匣为0后再次按左键，调用与R相同的GAS装填接口。装填中重复输入不重启计时，备用弹药耗尽时拒绝，默认无限备用弹药保持Demo原有补给体验。自动装填结束后需要再次按射击，不自动补射。
- 每把武器实例拥有弹匣、备用弹药和射击冷却；切换不刷新这些数值。玩家GAS只保存全局伤害/弹匣加成，弹药不在AttributeSet重复保存。
- 散弹枪一次扣一发、一次声音/后坐力，多个锥形射线独立碰撞；每颗先应用命中部位倍率，再对同一目标汇总施加一次GE。玩家全局伤害加成按弹丸数量分摊，避免霰弹获得数倍升级收益。
- 狙击枪右键循环一级镜、二级镜、退出；真实摄像机FOV缩放，圆形视野/黑色外围/细十字。开镜隐藏手臂和枪，默认开枪退镜；切换、装填、死亡、菜单和非战斗阶段强制恢复。
- 现有伤害/弹匣商店升级与清关奖励对所有武器生效；换枪不丢失升级。清关补给所有已有武器，重开生成全新装备实例。

## 职责与流程

2026-09-21接入弹药类型：安全区终端金币解锁并装配，主副武器共用普通/火焰/冰冻/穿透之一。`PerformBallistics`在射击内快照类型、聚合pellet伤害后每目标最多施加一层；穿透沿每颗弹丸轨迹最多额外命中一个敌人，墙体阻挡。原Fire/Reload/Aim输入链保持原规则，详细配置、GAS和回归见[弹药类型与Debuff设计](弹药类型与Debuff设计.md)。

分区受击改造：玩家武器的相机瞄准、相机到枪口防穿墙、枪口实际命中、穿透后段统一使用 `WeaponTrace`；敌人移动球 Ignore，随动画更新的 PhysicsAsset QueryOnly/Block。命中骨名精确映射手臂0.65、机身1、核心2，默认配置可编辑。空/未知骨或无真实刚体不产生默认机身伤害。每枪每敌的GE Context保留最重弹丸真实Hit；穿透后敌单独查询部位，DOT/爆炸保持独立配置。完整资产、公式、边界和本轮验证见[敌人分区受击](敌人分区受击.md)，不能用下方旧武器通过记录替代新专项结果。

`Enhanced Input IMC_Combat → UDemoWeaponComponent → Fire/Reload/Aim GA → 武器实例 → 射线/伤害GE/表现`。

`ADemoWeaponBase`拥有只读配置和受控运行状态，`ADemoHitscanWeapon`、`ADemoShotgunWeapon`、`ADemoSniperWeapon`区分弹道行为；步枪/手枪是Hitscan蓝图配置。装备组件管理槽位、输入调度、换枪中断、视角与主武器型号选择。角色只保留移动、GAS Avatar与输入转发。

外观初始化通过 `ApplyVisualMesh()` 二选一设置实例组件：保留原 `WeaponMesh` 根组件以兼容已保存蓝图，静态模式清空其骨骼资源并显示子组件 `StaticWeaponMesh`。枪口、弹道起点、音效和枪口粒子均读取当前外观上的 `Config.MuzzleSocket`；丢失挂点记录原因并沿用相机偏移回退。两组件均禁用碰撞、仅拥有者可见；装备/开镜隐藏整个 Actor，不产生旧枪叠影。`bHideSupportArm` 只控制模板左臂显示，手枪启用、长枪恢复，不改变动画时间或 GAS 状态。

GAS Fire的CheckCost/ApplyCost、CheckCooldown/ApplyCooldown读取/提交同一武器实例。装填AbilityTask保存弱武器引用，完成时必须仍是当前武器且仍在Combat，取消时不转移弹药。开镜由独立Aim GA持有Aiming标签。

Input Action包含Fire、Reload、Aim、EquipPrimary、EquipSecondary、CyclePrimary；不使用Triggered每帧发射。菜单期间移除Combat映射，数字1/2/3继续服务商店/奖励；恢复映射时忽略仍按住的键，避免关菜单后误开火。游戏阶段仍在C++校验，映射不承担权限。

## 分类与维护

代码位于 `Source/FPSDemo/Weapons/`；蓝图位于 `/Game/Weapons/Blueprints/`，动作与映射位于 `/Game/Weapons/Input/`；资产统一由Editor脚本创建，不手写uasset。瞄准遮罩用Canvas几何绘制，按实际视口尺寸维持圆形，不依赖外部游戏贴图。

所有函数/回调入口及失败路径保留日志，配置/成员/参数附用途、单位和所有权注释。单人Standalone/PIE为当前范围，暂不声称支持完整联机预测与复制。

## 配置与扩展

在Content Browser打开 `/Game/Weapons/Blueprints/BP_Weapon_*`，进入Class Defaults的Weapon→Config。修改后Compile/Save；新配置在下一次生成角色/武器时生效，不在运行中热改当前实例。`DemoWeaponComponent`的PrimaryWeaponClasses和SecondaryWeaponClass指定蓝图软类。默认值如下：

| BP | 原生父类 | 模式 / RPM | 基础伤害 | 弹匣 | 装填秒 | 射程cm / 散布半角 |
|---|---|---|---|---|---|---|
| Rifle | DemoHitscanWeapon | 自动 / 333.33 | 25 | 12 | 1.4 | 10000 / 0° |
| Pistol | DemoHitscanWeapon | 半自动 / 240 | 20 | 12 | 1.2 | 10000 / 0° |
| Shotgun | DemoShotgunWeapon | 半自动 / 75 | 8 × 8颗 | 6 | 2.2 | 3000 / 6° |
| Sniper | DemoSniperWeapon | 半自动 / 45 | 90 | 5 | 2.5 | 20000 / 腰射3°、镜内0° |

- 所有枪默认AmmoPerShot=1、无限备用；bInfiniteReserve=false时从InitialReserve（默认60）向弹匣转移，备用不足只补实际剩余发数，0备用拒绝换弹。AmmoPerShot可大于1；剩余弹量不足一次消耗时也走空弹装填路径。
- Mesh为SkeletalMesh；四枪AttachSocket为玩家手臂独立控制骨ik_hand_gun，AttachOffset为恒等变换，避免狙击右手拉栓带走枪身。MuzzleSocket是枪上的枪口；缺枪口回退到相机偏移并记录日志，缺手臂挂点直接拒绝初始化。旧GripPoint仅保留给未迁移外观。
- RPM合法1..1200；基础容量1..1000；初始弹量0..基础容量；装填0.1..15秒；弹丸1..32，普通射线枪固定1颗；散布0..45度，射程100..100000cm。完整校验在FDemoWeaponConfig::Validate，非法/非有限值不允许初始化。
- 散弹在600cm后线性衰减，3000cm为20%伤害；单次总加成分摊后与基础伤害一起衰减。镜内FOV默认40/10，步速乘0.5，再与GAS Boss减速相乘；退出恢复进入前FOV。
- `Weapon → Damage → EnemyHitProfile` 默认为 `/Game/Data/Combat/DA_EnemyHitZones`，区域倍率在武器/弹药/距离计算后逐弹相乘。配置来源 `Config/Combat/EnemyHitZones.json` 通过Editor脚本导入，不在运行时读JSON；缺失或非法配置记录回退到原生完整骨白名单。新增骨必须同步表与PhysicsAsset，不能以扩大移动球作为修复。
- 四枪的Idle/Fire/ReloadAnimation旧字段已清空，统一使用WeaponAnimLayerClass→AnimSet的待机、开火、普通/空仓换弹配对资源；手臂资源必须匹配共享模板骨架，枪械资源匹配各枪骨架。旧字段仅用于无LayerClass的外部兼容武器，不与新系统同时播放。GAS计时与唯一补弹仍不依赖动画Notify。
- `OnWeaponShot`、`OnWeaponEquipped`是蓝图表现扩展事件，C++先记录入口并完成状态修改；蓝图只追加表现，不重复扣弹/伤害。自定义弹道可从原生派生类覆盖PerformBallistics；新增枪种一般只需派生BP改Config。

## 空弹装填执行顺序与失败处理

### 第一人称四枪换弹、动画层与同步音效（2026-09-21实现）

本节说明已经接入的四枪换弹框架。运行资产包括4个骨骼枪、8个机械换弹Sequence、16个手臂Sequence（每枪Idle、Fire、普通换弹、空仓换弹）、12个Montage（4开火、8换弹）、1个ALI、固定主图、公共武器层、4个配置子类，以及21个原创短机械SoundWave。八个动作对分别引用所需声音事件；“21”是声音资源数量，不是八套换弹的事件总数。

制作流程已根据现有资产细化：枪械机械动作在Blender制作并导入UE；`UDemoFPSequenceAuthoring`在UE编辑器采样真实机械Sequence，通过离线TwoBoneIK烘焙共享手臂的标准动画资源。手臂与枪械并非在同一Blender场景中制作。运行时不执行这套离线烘焙器，公共AnimBP只保留待机支撑手IK；换弹时IK权重为0，直接使用烘焙后的双手轨迹。

#### 动作与玩法边界

沿用Breach深灰金属、灰白护板、少量青色标识的工业风格。四枪共用整体结构，通过机械部件、动作幅度和握持配置区分；散弹枪仍为可拆卸弹匣。

| 武器 | 普通换弹：开始时Ammo>0 | 空仓换弹：开始时Ammo==0 | 当前ReloadSeconds |
|---|---|---|---:|
| 手枪 | 左手取出、插入并压实弹匣，回到单手展示 | 换匣后操作套筒并复位 | 1.2 |
| 步枪 | 枪身侧倾，左手换弹匣后恢复护木支撑 | 换匣后增加拉机柄/枪机操作 | 1.4 |
| 散弹枪 | 更换宽短弹匣，动作幅度体现重量 | 换匣后增加枪机操作 | 2.2 |
| 狙击枪 | 左手更换短弹匣并恢复支撑 | 左手回护木支撑，右手操作枪栓再回握把 | 2.5 |

普通/空仓均适配同一个`Config.ReloadSeconds`，播放速率由素材长度除以该时长得到，没有新增两套玩法装填速度。当前没有独立膛内弹或容量+1规则；弹匣交接不丢弃剩余弹药。AmmoPerShot>1且余弹不足一次射击时也可以请求装填，但只要Ammo>0仍选择普通版本。清关、商店、解锁、存档及射击数值沿用原有规则。

#### 固定主图、公共武器层与配置子类

```text

  Linked Anim Layer：ALI_FPWeaponLayers.WeaponBasePose
    → FPAction Slot
    → Local To Component
    → TwoBoneIK（hand_l，以ik_hand_gun为目标空间）

    → Output

UDemoWeaponLayerAnimInstance
  └─ ABP_FPWeaponLayers_Base
       WeaponBasePose：原生IdlePose缓存 → 循环SequencePlayer → 输出
       ├─ ABP_FP_Pistol
       ├─ ABP_FP_Rifle
       ├─ ABP_FP_Shotgun
       └─ ABP_FP_Sniper
```

所有图资产位于`/Game/Weapons/Animations/`。ALI声明真实动画函数`WeaponBasePose`；主图与公共武器层都实现接口，运行时通过`LinkAnimClassLayers`链接配置子类。子类继承公共武器层，只配置Class Defaults中的`AnimSet`，不复制动画图、EventGraph或GAS逻辑。它们不是主手臂AnimBP的子类。

`FPAction`注册于手臂Skeleton的`DefaultGroup`。开火和换弹都在主实例Slot播放；武器Linked Layer不另开一套Montage播放器。主图TwoBoneIK读取`SupportHandGrip`和`SupportHandIKAlpha`，保持手腕相对旋转且不允许拉伸；换弹期间以及手枪隐藏左臂时运行权重为0。肘部方向在公共图作者代码中配置，改动后需要重建主图并检查镜头近裁剪。

| 实际类/接口 | 职责与生命周期 |
|---|---|
| `UDemoWeaponComponent::CommitEquip` | 统一初始手枪、读档、1/2切槽和终端换主枪的提交、取消及失败回滚 |
| `UDemoReloadAbility`与`ADemoWeaponBase` | 玩法校验、冻结动作序号/版本/时长、WaitDelay完成、唯一补弹及取消 |
| `UDemoWeaponAnimationComponent` | Pawn拥有的表现协调器；预检资源、链接层、驱动双网格和声音、恢复可见性 |
| `UDemoFPAnimInstance` | PreUpdate设置本帧Montage终点，NativeUpdate在引擎推进后测量真实双网格时钟并发布主图输入；工作线程只读取缓存 |
| `UDemoWeaponLayerAnimInstance` | 从本类AnimSet读取IdlePose，并复制主实例快照；不重复查询World/ASC |
| `UDemoAbilitySystemComponent::SetFirstPersonAnimationMesh` | 显式把ASC ActorInfo的网格/动画实例设为Mesh1P主实例 |
| `UDemoFPAnimationAuthoring` | 仅Editor创建、编译ALI/主图/公共层/4子类；ConfigureLayer写指定子类默认配置 |
| `UDemoFPSequenceAuthoring` | 仅Editor以60Hz采样机械动作、求双手IK并生成手臂Sequence/Montage |

快照`FDemoFPAnimationSnapshot`包含水平速度Speed（cm/s）、ReloadProgress（0..1）、bReloading、bAiming、bEmptyReload及EquipBlendAlpha（0..1）。bReloading来源于武器Gameplay状态，即使表现失败也不让IK误判装填已结束。工作线程图只读取发布的值与资源，不直接遍历World、Actor或ASC。当前没有在主图或子层绑定GameplayTagPropertyMap；Reloading Tag仍由GAS技能持有。

#### 配置入口、字段与资产路径

武器BP只通过`Config.WeaponAnimLayerClass`引用武器子类。子类CDO的`FDemoWeaponAnimationSet`是动画资源的唯一配置来源；组件读取它，技能通过组件播放。CDO不保存本次武器、计时或弹药。

| 配置位置 | 实际字段 | 用途、默认值或合法范围 |
|---|---|---|
| 武器Config | Mesh / StaticMesh | 四枪Mesh指向骨骼资产、StaticMesh为空；StaticMesh非空仍有外观优先级，迁移时必须清空 |
| 武器Config | WeaponAnimLayerClass | 对应ABP_FP_Pistol/Rifle/Shotgun/Sniper；验证原生层类型、WeaponBasePose、骨架和资源 |
| 武器Config | AttachSocket / AttachOffset | 当前为ik_hand_gun及恒等变换；不使用旧GripPoint逆旋转偏移 |
| 武器Config | ReloadSeconds | 唯一玩法时长，0.1..15秒，BeginReload时冻结 |
| AnimSet | IdlePose | 共享手臂Skeleton的循环持枪姿势；必填 |
| AnimSet | FireMontage | 共享手臂Skeleton的单FPAction Slot开火动作；接口允许空，交付四枪均配置 |
| AnimSet | TacticalReload / EmptyReload | 两份FDemoReloadAnimationPair，开始时按Ammo是否为0冻结选择 |
| AnimSet | SupportHandGrip | 左手腕在ik_hand_gun骨空间的位置，厘米；根据模型/手臂标定 |
| AnimSet | SupportHandIKAlpha | 0..1；导入配置手枪0、其余1，换弹时运行值强制为0 |
| AnimSet | MoveSwayCentimeters | 整体手臂组件移动轻摆幅度0..2cm，默认0.35；换弹时降为25% |
| AnimSet | EquipBlendSeconds | C++举枪偏移恢复秒数0..1，默认0.16；不产生切枪冷却。公共层惯性混合另在图中固定为0.16秒 |
| Reload Pair | ArmsMontage / WeaponSequence | 前者匹配共享手臂Skeleton及唯一FPAction Slot，后者匹配当前枪Skeleton；片长必须大于0 |
| Reload Pair | SoundEvents | 归一化声音事件数组；按NormalizedTime升序，四枪导入时检查完整事件集合 |
| Sound Event | NormalizedTime / Sound | 相对本次装填的0..1位置及短声音强引用，不负责弹药或零件状态 |
| Sound Event | VolumeMultiplier / PitchMultiplier | 音量0..2（代码默认1、当前导入0.75）；音高0.5..2（默认1） |
| AnimSet（可选兼容） | MagazinePresentationMesh / MagazineHandSocket / MagazineHandOffset | 静态手持弹匣、手部挂点（默认hand_l）、局部变换（默认恒等）；交付四枪的Mesh均为空 |
| Reload Pair（可选兼容） | MagazineDetachPhase / MagazineAttachPhase | 必须满足0≤Detach<Attach≤1；代码默认0.2/0.6，导入取manifest阶段；仅配置手持替身时用于显隐交接 |

当前八套动作直接使用真实`magazine`骨，换弹期间不隐藏枪内弹匣、不生成手部替身，也不创建物理弹匣、拾取物或第二套弹药。可选替身接口仅保留扩展兼容：实际配置非空时才会启用`ReloadHandMagazine`组件与HideBone交接；首版只读校验器会拒绝该配置，防止同屏出现两个弹匣。

#### 机械骨架、手臂烘焙与稳定挂点

#### 装备、换弹与声音的运行流程

1. 装备入口先验证槽位、解锁、阶段及资源。CommitEquip在预检成功后CancelActions、隐藏旧枪并提交候选；EquipWeapon解除旧层、链接新层，再检查引擎实际LinkedAnimLayer实例。失败回滚旧装备及旧层，不恢复已取消换弹，不刷新弹药或冷却。
2. SetAnimInstanceClass仅用于首次建立或异常重建主实例。正常切枪保持Mesh1P主实例地址不变，通过LinkAnimClassLayers切换层；链接当帧发布IdlePose/IK缓存。初始手枪、终端选枪、切槽和读档共用该路径。
3. R或空弹再次开火进入RequestReload→UDemoReloadAbility；停止连射并退镜。BeginReload设置bReloading、递增该武器ReloadSequence并冻结ReloadDuration、bEmptyReload。序号在开始新动作时递增，不靠切枪时随意修改序号取消。
4. 技能锁定原武器弱引用及序号，表现组件冻结自己的开始World时间和动作对。ASC显式使用Mesh1P主实例播放ArmsMontage，速率为Montage片长/ReloadDuration；技能同时创建UAbilityTask_WaitDelay，计时属于玩法。
5. 表现组件以`clamp((WorldTime-StartTime)/Duration,0,1)`生成共享phase。主实例PreUpdate在引擎UpdateMontage之前调用PrepareReloadAnimationUpdate，通过真实MontageInstanceID定位本次实例，并用SetNextPositionWithEvents指定本帧目标终点；保留引擎混合权重和事件区间，不重启Montage。枪网格使用停止自主播放的SingleNode实例，SetPosition按同一phase定位；枪械Tick同时依赖表现组件及手臂网格，避免附着骨更新前求值。暂停和时间缩放遵循World时钟。
6. 声音事件按相同phase触发。`NextSoundEvent`游标先消费再调用SpawnSoundAttached，即使跨过多个事件也按顺序各触发一次；音频无法播放不反复重试。21个原创WAV为48kHz单声道PCM16，按枪型对应拔匣、插匣、压实、套筒/枪栓等短声音。事件时刻来自机械manifest，完全不依赖AnimNotify。
7. WaitDelay完成后重新检查Avatar存活、Combat/菜单权限、原武器仍装备、序号匹配。只有CompleteReload转移弹药；bReloading置false使重复完成被拒绝。Montage、音效、Notify和表现组件均没有第二个补弹入口。
8. 正常结束或取消走ClearReloadPresentation：先启用bClearing防重入，再Stop/Destroy本次AudioComponent、停止对应手臂Montage、清空枪械Sequence回参考姿势、恢复真实弹匣及当前武器左臂状态。手枪空仓Sequence的0帧是套筒后锁，不能把该0帧当作通用待机复位。

主实例NativeUpdate在引擎UpdateMontage之后调用SampleReloadAnimationPhase，实际读取Montage实例GetPosition和枪网格GetPosition，按各自素材片长归一化；并未把目标phase复制为测量值。GetReloadPhaseAudit返回FDemoReloadPhaseAudit纯值副本：Sequence与MontageInstanceID标识本次动作，SampleCount为有效测量数量，ExpectedProgress/ArmsProgress/WeaponProgress为同帧进度，LastErrorSeconds/MaximumErrorSeconds为两网格与World时钟三者最大差换算后的玩法秒数。完成/取消后保留最近一次审计，下一次Begin重置；开始首帧SampleCount为0是合法状态。审计只证明动画时刻一致，手掌接触、手指和蒙皮仍需画面检查。

音效是本次动作拥有的短组件，清理会停止尚未结束的旧声音，避免取消后仍响旧换匣尾音；正常完成也执行同一清理。修改声音末尾事件时需检查尾音是否被玩法结束点截断。离线试听文件允许尾音自然延伸，不能据此宣称UE实际播放时长或混音已经验收。

ASC默认ActorInfo可能选中ACharacter自带Mesh，因此`SetFirstPersonAnimationMesh`显式写SkeletalMeshComponent、AnimInstance并清空AffectedAnimInstanceTag。主实例重建时组件取消旧动作、重新初始化/链接当前武器并刷新ASC。四枪旧IdleAnimation、FireAnimation、ReloadAnimation字段均已清空，执行路径改读AnimSet；无LayerClass的外部旧武器才保留PlayAnimation兼容入口。

#### 失败、中断与网络边界

| 情况 | 当前处理 |
|---|---|
| 满弹、无备用、已经装填、非法阶段或阻塞菜单 | 拒绝请求；不重启计时，不消费弹药 |
| 切枪、死亡、菜单、离开战斗或换World | 正式CancelActions/GA生命周期取消任务，停止旧表现，取消补弹为0 |
| Montage意外被停止/覆盖 | OnReloadMontageBlendingOut只在bInterrupted且仍匹配本次动作时取消Reload GA；正常混出不取消 |
| 旧完成/清理回调迟到 | 原武器和序号必须匹配；Montage混出回调额外匹配绑定时冻结的MontageInstanceID，同一资源重新播放也不得取消新动作 |
| 必需骨架、接口、挂点或动作对无效 | 装备预检拒绝，保留旧装备；链接失败回滚并输出原因 |
| 已合法开始后Montage无法播放 | 记录降级并清理残留；原玩法WaitDelay继续，避免表现故障永久阻塞装填；专项仍判表现失败 |
| 武器被外部销毁或主AnimInstance重建 | 弱引用/主实例身份检查触发清理；重建时取消并重新链接当前装备 |
| NullRHI或无声音设备 | 仍执行Gameplay与可求值骨骼逻辑；不会把声音事件日志或无渲染运行算作视听验证 |

当前范围为单人Standalone/单人PIE。GAS Reloading Tag仅表达装填状态，不包含枪型、动作版本或时间；当前主/子实例快照和枪械phase没有实现完整网络预测/复制。未来联机需要另行设计服务端弹药权威、拥有者预测/回滚、第三人称动作和迟到加入重建；ASC具有复制基础不代表本模块已经完成联机。

### 当前已实现的装填流程

1. IA_Fire Started→角色FirePressed→组件StartFire/TryFireHeld，检查当前装备、Combat和存活状态。
2. 不足一次开火成本时停止连射，调用RequestReload(true)，日志标记 `source=EmptyFire`；R调用同一函数，标记Manual。此分支不激活Fire、不扣弹、不设置射速冷却、不播放枪声。
3. RequestReload检查未满弹、未在装填、有备用，停止连射并退镜，激活UDemoReloadAbility。
4. GA锁定原武器弱引用，BeginReload后由WaitDelay等待该枪ReloadSeconds，重复输入不创建第二个任务。
5. 到时重新检查Avatar存活、Combat和当前装备仍是原武器；CompleteReload唯一地转移弹药，EndAbility清标签/状态。切枪、死亡、菜单或关卡切换取消任务，取消路径不补弹。
6. 结束后不恢复旧的按住状态，玩家需要松开并再次按下开火。

换枪保存旧枪弹药与冷却；选择主武器型号必须在Hub/Intermission、终端范围内且打开武器页，并验证永久解锁。初始化仅生成手枪，失败记录Loadout错误；主枪配置在首次终端装备时校验，失败保留旧装备，不生成未解锁库存。所有输入仍由C++/GAS检查权限，不把移除IMC当作唯一防护。
