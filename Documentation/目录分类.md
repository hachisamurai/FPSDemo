# 文件分类与维护约定

## 目的与范围

按功能定位代码、源素材、编辑器工具和最终资产，便于逐模块调试。本次移动项目 C++ 文件并同步模块根相对 `#include`，不修改 UObject 类名、模块名或已有蓝图资源路径。反射路径仍是 `/Script/FPSDemo.DemoCharacter` 等，无需 CoreRedirect。

## 依赖、验证和维护

### 弹药模块（2026-09-21）

`Source/FPSDemo/Weapons/Ammo/`存放目录和购买/装配组件；`GAS/Ammo/`存放原生GE、免疫条件、敌人状态与GC桥接；`Player/DemoAmmoMenu.cpp`和`UI/DemoAmmoHUD.cpp`负责终端交互。配置资产为`Content/Data/Ammo/DA_AmmoCatalog.uasset`，由`Tools/Unreal/create_ammo_assets.py`通过Editor创建；直接复用`Content/UI/Textures/ElementIcons/`既有四张弹药图标，不重复导入。流程、V4存档、配置范围与验证记录见[弹药类型与Debuff设计](弹药类型与Debuff设计.md)。

- 跨目录项目 include 使用 `Characters/DemoCharacter.h` 等模块根相对路径；generated.h 保留基本名且必须最后 include。
- FPSDemo.Build.cs 显式包含模块根，`bUseUnity=false` 检查独立翻译单元；不要使用全目标 `-DisableUnity`，源码引擎可能因此全部重编。
- `FPSDemoEditor` 是 `.uproject` 声明的 Editor/PostEngineInit 模块，UnrealEd/AudioEditor 依赖不进入 Runtime。
- PythonScriptPlugin、EditorScriptingUtilities 仅对 Editor 启用，以支持官方资产创建/导入/保存。JSON 不支持注释，模块与插件字段变更原因记录于本文。
- 分类后执行 Editor Development 编译与真实地图回归，确认 UHT、头文件、蓝图继承和 CDO 引用有效。IDE 文件列表未刷新时重新生成工程，不手改 Intermediate。
- 后续移动音频 `.uasset` 必须通过 Editor AssetTools 并修复引用，不能仅用文件系统移动；同步 Python 路径、C++ 硬引用和音频说明。
- 源 WAV 和脚本可正常分类，但移动后需维护 reimport 来源和文档。新增功能仍必须遵守 AGENTS.md 的日志、注释与说明要求。
