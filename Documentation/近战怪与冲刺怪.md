# 近战怪与冲刺怪

## 目的与设计

在已有追击/远程/侧翼兵之外增加两类纯近身敌人，提供能观察、能打断、能躲避的压力。`Melee`使用绿色灯带，`Charger`使用橙色灯带；复用现有小怪骨骼、受击部位、GAS健康与伤害、导航、死亡和银币结算，不新增第二套血量/伤害系统，也不改变本关怪物总数。

普通`Chaser`仍保留旧接触攻击与飞行物，新的Melee/Charger不允许发射飞行物，外部直接调用发射接口也拒绝。`UDemoCloseCombat`由Enemy Tick驱动，没有独立Tick、异步Lambda或延迟伤害Timer；返回true时完全接管旧移动/攻击分支，避免一次攻击叠加旧接触伤害。

## 核心流程

### 近战怪

沿NavMesh以模板速度×ApproachMultiplier×GAS移速追击，进入190cm三维距离且可见时开始0.45秒前摇。起手锁定水平朝向，自身显示红色壳，保持静止。到期重新检查距离、视线及相对锁向±65度扇形；满足才通过Health GE造成一次实时GAS AttackPower伤害，不满足则挥空。玩家可以退开或绕到侧后方，普通近战不享受Boss专用的DashEvading免伤。

结算前切入Recovery防止健康GE导致阶段切换重入。播放既有Melee碰撞/回收动作（并非新增完整武器挥砍动画），0.65秒硬直后再等待Attack.MeleeInterval才可再次起手。出生至少2秒缓冲，加入既有FormationSlot首发错峰。

### 冲刺怪

距离350..1100cm、视线可见、高差小于150cm且冷却完成时，锁定玩家当前水平朝向，原地预警0.8秒，显示自身红壳与固定直线地面带。预警与冲刺期间不会追踪玩家；模型朝向也读取该锁定方向，避免视觉上转头但路线不转。

冷却/出生缓冲期间在最小起跑距离+100cm处等待，避免未出招就贴脸退化为近战；若玩家主动贴近，则使用同一套有前摇近战。冲刺开始后按1300cm/s×GAS移速直线Sweep，最大行程1400cm：碰到玩家一次伤害为实时AttackPower×1.5，玩家有效冲刺窗口可免掉此次突进碰撞；侧移离开线路也可躲避，无额外回血。碰墙/其他敌人停止，不友伤、不穿透，进入相同硬直。

每步还在小范围内投影NavMesh，拒绝越过导航边界或明显高度变化；这仍是现有平坦竞技场逻辑，不是悬崖跨越/楼梯移动能力。行程结束/撞墙/命中后都只能结算一次；恢复结束后计6秒冲刺冷却。冲刺伤害没有新增击退，和Boss固定50伤害的俯冲分开。

## 配置与混编

配置入口`DT_Enemies → Drone → Tactics / CloseCombat`；源码`Config/Combat/Enemies.json`，由`Tools/Unreal/import_combat_tables.py`通过Unreal Editor保存资产。JSON不支持注释，本文负责字段说明。表内手改会被后续JSON导入覆盖。新USTRUCT/枚举先完整编译Editor，不能只靠Live Coding。

Tactics.Role追加Melee/Charger，旧枚举值保持稳定。MixedRoles为1..16项非Mixed角色数组，默认`Chaser,Ranged,Flanker,Melee,Charger`，仅直接生成/其他玩法仍按此列表循环。当前生产战役和无尽使用[战役配置与难度](战役配置与难度.md)的关号随机池覆盖实例角色：普通关只近战/冲刺，每5关加入远程且三种齐全，每10关在三种小怪之外加Boss。模板CloseCombat/Attack数值不被覆盖，排队/最大存活数机制保留。直接生成时Role可固定兵种，Tactics关闭或bUseTactics=false保持旧行为；战役随机池会显式启用对应战术组件。

| CloseCombat字段 | 默认 | 单位/合法范围 |
|---|---:|---|
| MeleeWindup | 0.45 | 前摇秒，0.2..2 |
| MeleeReach | 190 | 起手/命中三维距离cm，150..260 |
| MeleeHalfAngle | 65 | 锁定朝向扇形半角度，20..90 |
| Recovery | 0.65 | 挥击/冲刺恢复秒，0.2..2 |
| ApproachMultiplier | 1.5 | 导航速度倍率，1..2.5，另乘GAS |
| ChargeWindup | 0.8 | 冲刺预警秒，0.3..2 |
| ChargeMinRange | 350 | 起手最小水平距离cm，250..600 |
| ChargeMaxRange | 1100 | 最大距离cm，必须大于Min且≤1800 |
| ChargeSpeed | 1300 | cm/s，600..2500，另乘GAS |
| ChargeDistance | 1400 | 行程cm，400..2000且≥MaxRange |
| ChargeCooldown | 6 | 恢复结束后秒数，1..20 |
| ChargeDamageMultiplier | 1.5 | 乘实时GAS AttackPower，0.5..3 |

近战冷却复用Attack.MeleeInterval；难度AttackFrequencyMultiplier只缩短间隔和ChargeCooldown，不缩短前摇/硬直，不改变速度/范围。攻击力已经包含关卡/难度倍率，组件不能再重复乘算。数值拒绝NaN/无穷/越界，混编数组拒绝空、超过16项、递归Mixed与非法枚举；生产配置错误拒绝开局，直接非法CloseCombat调用记录警告并禁用组件。

## 状态、依赖与失败处理

阶段为Idle、MeleeWindup、ChargeWindup、Charging、Recovery。冰霜减速作用于导航及真正突进速度，Frozen打断新近身攻击并关闭预警，不会解冻后结算旧伤害；这一点是新纯近身兵种规则，原射击敌人与Boss既有定身语义不变。死亡、玩家死亡、离开Combat、CancelPendingAttacks、EndPlay沿同一Cancel入口清理。暂停冻结World时间和Enemy Tick，无后台追击。

预测路径只用于导航范围守卫，真正碰撞由Sweep决定；地面预警显示最大固定线路，遇墙会提前停止，不代表允许穿墙。无网格时导航/突进均不能绕过限制。当前复用小怪模型及近战回收动画，不新增独立兵种模型或冲刺专用Montage；角色灯带、前摇壳、方向带和锁定朝向提供行为辨识。当前范围仍是单人Standalone/PIE，不声称新增完整联机预测/特效同步。

日志`CLOSE_CONFIG`、`CLOSE_PHASE`、`MELEE_MISS`、`CLOSE_HIT`、`CHARGE_STOP`、`CHARGE_EVADED`、`CLOSE_CANCEL`用于诊断。所有入口保留CALL/TICK，状态切换普通Log，高频守卫不刷Warning。方向只保存FVector值，不持有跨World玩家引用。预警组件由Enemy持有，取消隐藏、Actor销毁释放；硬引用既有引擎网格与Editor红材质供Cook，无手写二进制资产。

## 验证方法

独立游戏参数`-DemoEnemyAttackTest -DemoCloseCombatTest`，复用隔离测试档与禁云入口；地图`/Game/Whitebox/Maps/L_ThreeSector_Whitebox`。成功标记`DEMO_CLOSE_COMBAT_SUCCESS`，失败`ATTACK_TEST FAIL`；必须结合日志与退出码，不能只看0。加`-DemoCloseCapture -RenderOffscreen -windowed -ForceRes -ResX=1280 -ResY=720`采集真实预警截图`Saved/Screenshots/CloseCombat/ChargeWindup.png`。

专项验证真实生产首关混编、非法配置、纯近身拒绝飞行物、出生缓冲/前摇、近战命中与走开、冰冻打断、冲刺命中/侧闪、固定方向、实体墙Sweep、切阶段、真实Dash GA窗口以及死亡取消。原战术/攻击/导航回归按各自测试参数独立执行，不同时驱动多个状态机。手感、密集群体性能和所有地图布局需要后续试玩评估。
